## 2026-10-09 · 1.0.1 标题栏拖动修复

用户实际使用发现顶部标题栏拖不动。确认本机安装的 Tauri 2 API 与原生拖动脚本要求 `core:window:allow-start-dragging`，而 `core:default` 不包含该权限。

补充最小窗口拖动权限，未改变前端布局或任务行为。重新构建 `.app` 与 `.dmg` 后，从最终交付目录启动 1.0.1。通过原生界面拖动顶部空白区域，并以只读系统窗口坐标检查确认窗口发生移动。升级前后正式任务文档 SHA-256 一致。

公开仓库提供 1.0.1 的 DMG、保留可执行权限的 `.app.zip` 与两者 SHA-256 校验值。Mac 原生解压后，可执行文件哈希与本机应用一致。
